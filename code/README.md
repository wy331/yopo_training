## Ubuntu 常用命令记录

### 文件和目录操作
- `pwd` —— 查看当前工作目录的绝对路径
- `ls -la` —— 列出当前目录下所有文件和文件夹（含隐藏文件）
- `cd ~` —— 返回用户主目录
- `cd ..` —— 返回上一级目录
- `mkdir 文件夹名` —— 创建新文件夹
- `touch 文件名` —— 创建空文件

### Git 操作
- `git status` —— 查看当前仓库状态
- `git add .` —— 添加所有改动到暂存区
- `git commit -m "说明"` —— 提交并记录修改
- `git push` —— 将本地提交推送到远程仓库
- `git pull` —— 从远程仓库拉取最新更新

### 系统管理
- `sudo apt update` —— 更新软件包列表
- `sudo apt install 软件名` —— 安装软件
- `python3 --version` —— 查看 Python 版本
- `lsb_release -a` —— 查看 Ubuntu 版本
